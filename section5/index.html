A finite bound from Cantelli

Section 5: Sustained guarantees and a finite bound

Sustained assurance looks at every larger sample size, so a finite calculation needs a point after which every count passes. This animation follows the Cantelli route to that point for the example of Section 2. Cantelli's inequality caps the probability beyond any point using only the posterior mean μ and standard deviation σ. The cap falls to 5% at √19 standard deviations from the mean, so every 90% equal-tailed interval fits between fences 2√19 σ apart. At a fixed sample size every posterior has the same concentration c = a + b + n, and σ is largest when the posterior mean is 1/2, which bounds every interval width by √(19/(c + 1)). Once that bound falls below the target width, every count passes and A(n) = 1. For this example the Cantelli route certifies n ≥ 212, while every count already passes from n = 18. The sub-Gaussian bound used in the paper gives the smaller certificate n ≥ 57.
