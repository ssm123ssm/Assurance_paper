# Nonmonotone precision assurance, companion material

Explainers for the paper "Nonmonotone precision assurance in Bayesian sample size determination for binomial proportions" (Manathunga, Heath, Russell).

- `videos/` holds rendered animations ready to embed.
- `animations/` holds the Manim source that produces them.

To embed the Section 2 animation in a page,

```html
<video src="videos/section2_assurance.mp4" poster="videos/section2_assurance_poster.png"
       controls playsinline preload="metadata" style="width:100%"></video>
```
